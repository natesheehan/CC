# How it works

## 1. Create a map

Start a new concept map for a topic: a course, a research area, or anything you want to think through. Give it a name and an optional description.

## 2. Add concepts

Each concept is a node on the map with a name, definition, examples, source links, and an optional quiz question. Drag nodes around to arrange the map however makes sense to you.

## 3. Link concepts with relations

Draw a relation between two concepts and choose what kind it is: type of, part of, produces, counteracts, and more. Use built-in relation types or create your own. Mark a relation as one-directional or multi-directional, then describe what the link means.

## 4. Discuss relations

Click any relation on the map to open its comment thread. From a concept's panel, you can also explore every relation touching that concept, grouped by type.

## 5. Share and revisit

Every concept and relation gets a shareable URL, so you can link straight to a specific node or link in a conversation. An activity feed tracks who added or edited what, and when.

## 6. Browse the concept directory

The Concepts tab is a searchable dictionary of every concept across every map. Use it to find out whether a concept already exists before adding a duplicate.
